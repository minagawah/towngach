# Translation Rules

This document describes of how technical terms are
presented in documentations throughout the repo.

- Technical terms for East Asian astrology or
  divination are **bold** and enclosed in
  double quotes, for example **Solar Term**.
- Technical terms are followed by their translations
  in parentheses, for example **Solar Term**
  (節氣 / 节气 / jie-qi / tiết khí).
- English terms normally show translations
  in a specific order.
  - For example **Solar Term** (節氣 / 节气 /
    jie-qi / tiết khí).
  - Here is the order:
    - **"ja"** (Japanese)
    - **"zh_tw"** (Traditional Chinese)
    - **"zh_ch"** (Simplified Chinese)
    - **"zh_ch alphabetical expression"**
    - **"vi"** (Vietnamese)
- Terms that are not English omit the
  **"zh_ch alphabetical expression"** entry.
  For example **"Jia-Zi"** (甲子 / giáp-tý)
  instead of **"Jia-Zi"** (甲子 / jia-zi / giáp-tý).
- If 2 or more translation entries are identical,
  the duplicate entries are shown only once.
  For example **One-White** (一白 / yi-bai / nhất bạch)
  instead of **One-White** (一白 / 一白 / 一白 /
  yi-bai / nhất bạch).
- The **"zh_ch alphabetical expression"** and
  **"vi"** (Vietnamese) are lowercase.
  For example **"jia-zi"** (alphabets) and
  **"giáp tý"** (vi).
- The **"zh_ch alphabetical expression"**
  uses hyphens between words.
  For example **"jia-zi"**.
- The first occurrence of a term in a document
  shows the full translation set. Later
  occurrences use only the **"ja"**
  (Japanese) entry.
- The "二十四節気" are normally written using
  the **"zh_ch alphabetical expression"**
  rather than an English translation.
  For example **"Li-Chun"** (立春 / lập xuân)
  instead of **Beginning of Spring** (立春 /
  li-chun / lập xuân).
- When **"sexagenary"** means "六十干支",
  the preferred term is **"Sixty Gan-Zhi Unit"**.
  Generic uses of **"sexagenary"** are unchanged.
- Individual "干支" are written using the
  **"zh_ch alphabetical expression"**,
  such as **"Jia-Zi"** (甲子 / giáp tý).

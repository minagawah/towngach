# Translation Rules

This document describes of how technical terms are presented in documentations throughout the repo.

- Technical terms for East Asian astrology or divination are **bold** and enclosed in double quotes, for example **"Forward Flight"**.
- Technical terms are followed by their translations in parentheses, for example **"Forward Flight"** (順飛 / 顺飞 / shun-fei / thuận phi).
- English terms normally show translations in this order: **"ja"** (Japanese), **"zh_tw"** (Traditional Chinese), **"zh_ch"** (Simplified Chinese), **"zh_ch alphabetical-expression"**, and **"vi"** (Vietnamese).
- Terms that are not English omit the **"zh_ch alphabetical-expression"** entry.
- If 2 or more translation entries are identical, the duplicate entries are shown only once.
- The **"zh_ch alphabetical-expression"** and **"vi"** (Vietnamese) are lowercase; the **"zh_ch alphabetical-expression"** uses hyphens between words.
- The first occurrence of a term in a document shows the full translation set. Later occurrences use only the **"ja"** (Japanese) entry.
- The "二十四節気" are normally written using the **"zh_ch alphabetical expression"**, such as **"Li-Chun"** (立春 / lập xuân), rather than an English translation.
- When **"sexagenary"** means "六十干支", the preferred term is **"Sixty Gan-Zhi Unit"**. Generic uses of **"sexagenary"** are unchanged.
- Individual "干支" are written using the **"zh_ch alphabetical-expression"**, such as **"Jia-Zi"** (甲子 / giáp-tý).
